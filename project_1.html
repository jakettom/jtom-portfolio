Multi-Cycle MIPS Processor

Project Overview

Objective

To design and implement a multi-cycle MIPS CPU on an FPGA by developing the core processor logic, including the datapath, control logic, and ALU. The project also included creating a custom Python assembler to translate MIPS assembly into machine code while using provided top-level FPGA wiring code and pin constraints.

This project was completed as part of a Computing Hardware class.

Details

  • Designed support for R-type, I-type, and J-type instructions
  • Designed the ALU strictly at the logic-gate level
  • Implemented arithmetic, shift, and comparison operations
  • Added overflow, zero, and equality error flags

Tools & Software

  • SystemVerilog
  • Python
  • Multi-cycle MIPS architecture
  • XEM7310 FPGA board
  • Vivado for simulation and synthesis

Outcome

Successfully executed sets of R-type, I-type, and J-type MIPS assembly instructions on FPGA hardware. The processor produced correct values on a simulated register file and data/instruction memory.

Received an A letter grade on the project.
