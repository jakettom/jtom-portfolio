Multi-Cycle MIPS Processor

Project Overview

Objective

To design and implement a multi-cycle MIPS CPU on an FPGA by developing the core processor logic (datapath, control logic, ALU) and creating a custom Python assembler to translate MIPS assembly into machine code, while using provided top-level FPGA wiring code and pin constraints. (Computing Hardware class project)

Details

  • Designed for R-type I-type J-type instructions
  • ALU designed strictly at the logic gate level
  • ALU supported basic arithmetic, shift operations, comparison operation, error flags (overflow, zero, equal)

Tools & Software

  • SystemVerilog (CPU, gate-level ALU)
  • Python (custom MIPS assembler)
  • Multi-cycle MIPS architecture
  • XEM7310 FPGA board
  • Vivado (simulation and synthesis)

Outcome

Successfully executed given sets of R-type, I-type, and J-type MIPS assembly instructions on FPGA hardware. Produced correct values on a simulated register file and data/instruction memory. Received an A letter grade on the project.
